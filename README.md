# Conquer Academy

Proyecto de práctica en HTML sobre una academia online ficticia de formación en tecnología.

## Contenido

- Página de inicio con información de la academia, cursos y noticias.
- Página sobre la academia.
- Listado de cursos y página de detalle para cada curso.
- Listado del blog y páginas de artículos.
- Formularios de registro, inicio de sesión y contacto.
- Aviso legal.

## Cómo abrir el proyecto

Abre el archivo `index.html` en un navegador.

El sitio es estático. Los formularios son ejemplos y no guardan ni envían información. El mapa de la página de contacto necesita conexión a Internet.
